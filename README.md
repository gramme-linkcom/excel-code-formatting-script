# excel-code-formatting-script

# 使い方
<h3> 1. (２回目以降不要です。)新しいエクセルのファイルを作成します。</h3>

<h3>2. 下記の動画のように、リボンメニューの「開発」タブから「Visual Basic」を開きます。</h3>
<img src="https://github.com/gramme-linkcom/excel-code-formatting-script/blob/main/design/%E7%94%BB%E9%9D%A2%E9%8C%B2%E7%94%BB%202026-10-13%20174449.gif">

<h3> 3. 下記の動画のように、タブを開きます。</h3>
<img src="https://github.com/gramme-linkcom/excel-code-formatting-script/blob/main/design/%E7%94%BB%E9%9D%A2%E9%8C%B2%E7%94%BB%202026-10-13%20175241.gif">

<h3>4. <a href="https://github.com/gramme-linkcom/excel-code-formatting-script/blob/main/Module1">ここ</a>から、ソースコードをコピーして、先程のタブに貼り付けます。</h3>

<h3>5. そのままウィンドウを閉じます。</h3>

<h3>6. 下記の動画のように、ボタンを追加して、関数を割り当てます。</h3>
<img src="https://github.com/gramme-linkcom/excel-code-formatting-script/blob/main/design/%E7%94%BB%E9%9D%A2%E9%8C%B2%E7%94%BB%202026-10-13%20180651.gif">

<h3>7. セルの`I9`にフォントの名前、セルの`I11`にフォントサイズを指定します。</h3>
<h3>8. セルの`C2`をクリックして、ソースコードを貼り付けます。</h3>
<h4>ここまでのことを行い、デザインなどを整えると、下記の画像のようになります。(ソースコードは貼り付けていません。)<h4>
<img src="https://github.com/gramme-linkcom/excel-code-formatting-script/blob/main/design/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202026-10-13%20181220.png">

<h3>9. 6と同じ手順でボタン設定を行っている場合、ソースコードを貼り付けたあとに上のボタンを押すことで整形が行われます。</h3>
<h3>10. 列番号`2`にあるコードをすべてコピーして、Word側でペーストします。</h3>
<h3>11. 必要であれば、word側で多少手直ししてください。</h3>
<h3>12. ソースコード整形を行うボタンの下にあるボタンを押すことで、ソースコードを丸ごと消すことができます。</h3>
